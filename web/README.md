# AR Music Game - Web版（キーボードプレイ）

Processing版（`R4_main/R4_main.pde`）の音楽ゲームをWebアプリに移植したものです。
ARプレイは含まれず、キーボードプレイのみ対応しています。

## 起動方法

音声・譜面ファイルを読み込むため、ローカルサーバーが必要です（`index.html` を直接開いても動きません）。

- 一番簡単な方法: リポジトリ直下の **`start_web.bat` をダブルクリック**
  （Python製サーバーが起動し、ブラウザで http://localhost:8765 が開きます）
- または手動で:

  ```
  python -m http.server 8765 --directory web
  ```

  を実行して http://localhost:8765 を開く。

GitHub Pages や Netlify などの静的ホスティングに `web/` フォルダをそのまま置いても動きます。

## 遊び方

| 画面 | 操作 |
|------|------|
| タイトル | STARTボタンをクリック（または ENTER） |
| 選曲 | マウスホイール / ↑↓ で選曲、ENTER または曲名クリックで開始、LYRICSボタンにマウスを乗せると歌詞表示 |
| プレイ | **1・2・3・4 キー**（または D・F・J・K）で各レーンのノーツを叩く。ESCで選曲に戻る |
| リザルト | Retry（ENTER）でもう一度、EXIT（ESC）でタイトルへ |

ノーツは奥から手前に流れてきます。手前の判定ラインに重なった瞬間にキーを押すとヒットです。
連続ヒットでコンボが伸び、ミス（ノーツの見逃し）でコンボが途切れます。

## タイミング補正（譜面と音楽のズレ調整）

譜面は `create_sheetMusic.pde` で「スケッチ起動からの経過時間」で記録されているため、
録音時の曲再生開始タイミング次第で曲ごとに一定のズレが乗っています。
Web版では曲ごとに補正値（`game.js` の `SONGS[].offset`、単位: 秒）を持ち、
`tools/estimate_offsets.py`（音声のオンセットと譜面の相互相関で推定）の結果を初期値にしています。

ただし曲はビートが周期的なので、**1拍・1小節ずれた候補と真のズレを自動で確定することはできません**。
最終確認は耳で行ってください。プレイ中に以下のキーが使えます：

| キー | 動作 |
|------|------|
| **A** | オートプレイのON/OFF。ノーツが判定バーを通る瞬間にドラム音が自動で鳴るので、**ドラムが曲のリズムに乗っていれば補正が合っています** |
| **Tab** | 自動推定の補正候補を順に切り替え |
| **← / →** | 補正を ±10ms 微調整（Shift併用で ±100ms、押しっぱなし可） |
| **0** | 補正なし（0ms）にリセット |

調整した補正値はブラウザの localStorage に曲ごとに保存され、次回以降も適用されます。
確定した値を `game.js` の `SONGS[].offset` に書き込めば、どの環境でも初期値として使われます。

おすすめの手順: プレイ開始 → A でオートプレイON → ドラムがズレていたら Tab で候補を切り替え
→ 一番合う候補を ←→ で微調整 → A で解除してプレイ。

## Processing版から引き継いだ仕様

- 全10曲・譜面・歌詞・ジャケット画像・ドラム効果音
- ノーツ速度: 600px/秒（元の10px/フレーム@60fps相当）、判定範囲: x=0〜130px
- ゲーム開始2秒後に音楽再生開始（ノーツのタイミングと同期）
- スコア計算: ヒット数 × floor(1000 ÷ 総ノーツ数)
- リザルトのあおりコメント・作詞クレジット

## Web版での改良点

- フレームレート非依存のノーツ移動（高リフレッシュレートモニタでも同じ速度）
- D/F/J/K キーでもプレイ可能
- 矢印キー選曲・クリック選曲、リトライで同じ曲を即再プレイ
- キー押下フラッシュ・HIT!表示、ロード画面

## ファイル構成

```
web/
├── index.html   # エントリポイント
├── style.css    # レイアウト（4:3を維持して画面にフィット）
├── game.js      # ゲーム本体（状態機械: title → select → play → result）
└── assets/      # R4_main/data からコピーした曲・譜面・歌詞・画像
```

曲を追加する場合は `game.js` 先頭の `SONGS` 配列にエントリを足し、
対応するファイルを `assets/` に置いてください。譜面は Processing版の
`create_sheetMusic.pde` で作成した `keyLog.txt` 形式（`At 秒 seconds ---- レーン番号`）がそのまま使えます。
